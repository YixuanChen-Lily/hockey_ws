# Hockey Controller

This ROS 2 package contains the mission-level controllers for the air hockey
robot project. The main workflow is:

1. park near the cushion and pick up or prepare the hockey stick,
2. navigate safely with CLF-CBF-QP obstacle constraints,
3. align the robot for shooting,
4. spin to hit the puck,
5. coordinate passer and shooter robots through a simple team status topic.

## Main Nodes

### `safe_navigation_server`

Action server for point navigation:

```text
safe_navigate_to_point
```

It uses a CLF-CBF-QP controller. The CLF drives the lookahead control point
toward the target, while the CBF constraints keep the robot outside static and
pose-updated obstacle circles.

The node can avoid:

- cushion obstacles generated by the parking planner,
- other robots from `safe_obstacle_robot_ids`,
- puck or goal pose topics from `safe_obstacle_pose_topics`.

### `spin_server`

Action server for in-place rotation:

```text
spin
```

It is used for yaw alignment and for the final puck-hitting spin.

### `shooting_server`

Action server for puck shooting:

```text
shoot_puck
```

It reads the puck and goal poses, computes the shooting geometry, navigates to
the robot point, moves the virtual point forward by the lookahead distance,
aligns to the shooting yaw, and then spins to hit the puck.

Supported roles:

- `single`: shoot directly and then retreat to the cushion side.
- `passer`: shoot toward a pass target and publish `PASS_DONE`.
- `shooter`: wait near the goal-side offset point until receiving `PASS_DONE`.

### `mission_manager`

Top-level mission state machine. It starts parking, configures safe navigation
obstacles, handles manipulator steps when enabled, runs shooting, and manages
passer/shooter coordination.

Start the mission with:

```bash
ros2 service call /mission/start std_srvs/srv/Trigger
```

For a namespaced robot, include the namespace:

```bash
ros2 service call /robot9/mission/start std_srvs/srv/Trigger
```

### `parking_plotter`

Optional plotter for debugging the parking plan, obstacles, puck/goal geometry,
robot trajectory, and lookahead virtual point. It writes a PNG image to the
configured `plotter_output_path`.

### `plot_clf_cbf_log`

Utility script for plotting the CLF-CBF diagnostic CSV:

```bash
ros2 run hockey_controller plot_clf_cbf_log
```

## Build

From the workspace root:

```bash
colcon build --packages-select hockey_controller
source install/setup.zsh
```

Use `setup.bash` instead if the terminal is running bash:

```bash
source install/setup.bash
```

## Launch Examples

### Robot 8 as shooter

```bash
ros2 launch hockey_controller mission.launch.py \
  teammate_robot_id:=9 \
  robot_id:=8 \
  target_pose_topic:=/vrpn_mocap/hockey_sticks_1/pose \
  cushion_length:=0.3 \
  cushion_width:=0.42 \
  parking_front_axis:=x \
  front_normal_sign:=1.0 \
  cushion_obstacle_axis:=local_y \
  desired_normal_distance:=0.8 \
  parking_lateral_offset:=0.10 \
  parking_robot_safety_radius:=0.0 \
  parking_safety_margin:=0.0 \
  safe_obstacle_robot_ids:="[9]" \
  safe_obstacle_pose_topics:="['/vrpn_mocap/hockey_puck_blue/pose', '/vrpn_mocap/hockey_goal_2/pose']" \
  safe_obstacle_pose_radii:="[0.10, 0.20]" \
  shooting_enabled:=true \
  shooting_role:=shooter \
  puck_pose_topic:=/vrpn_mocap/hockey_puck_blue/pose \
  goal_pose_topic:=/vrpn_mocap/hockey_goal_2/pose \
  safe_lookahead_distance:=0.45 \
  shooting_contact_gap:=0.0 \
  shooting_spin_direction:=ccw \
  plotter_enabled:=true \
  use_manipulator:=false \
  shooting_puck_obstacle_radius:=0.10 \
  shooting_center_to_puck_distance:=0.40 \
  shooting_spin_angle_deg:=110.0 \
  shooting_angular_speed:=2.5 \
  shooting_offset_x:=0.8 \
  shooting_offset_y:=-0.8 \
  safe_obstacle_safety_margin:=0.10
```

### Robot 9 as passer

```bash
ros2 launch hockey_controller mission.launch.py \
  namespace:=robot9 \
  robot_id:=9 \
  target_pose_topic:=/vrpn_mocap/hockey_sticks_1/pose \
  cushion_length:=0.3 \
  cushion_width:=0.42 \
  parking_front_axis:=x \
  front_normal_sign:=1.0 \
  cushion_obstacle_axis:=local_y \
  desired_normal_distance:=0.8 \
  parking_lateral_offset:=0.10 \
  parking_robot_safety_radius:=0.0 \
  parking_safety_margin:=0.0 \
  safe_obstacle_robot_ids:="[8]" \
  safe_obstacle_pose_topics:="['/vrpn_mocap/hockey_puck_blue/pose', '/vrpn_mocap/hockey_goal_2/pose']" \
  safe_obstacle_pose_radii:="[0.10, 0.20]" \
  shooting_enabled:=true \
  shooting_role:=passer \
  puck_pose_topic:=/vrpn_mocap/hockey_puck_blue/pose \
  goal_pose_topic:=/vrpn_mocap/hockey_goal_2/pose \
  safe_lookahead_distance:=0.45 \
  shooting_contact_gap:=0.0 \
  shooting_spin_direction:=ccw \
  plotter_enabled:=true \
  use_manipulator:=false \
  shooting_puck_obstacle_radius:=0.10 \
  shooting_center_to_puck_distance:=0.40 \
  shooting_spin_angle_deg:=110.0 \
  shooting_angular_speed:=2.5 \
  shooting_offset_x:=1.5 \
  shooting_offset_y:=0.0 \
  safe_obstacle_safety_margin:=0.10
```

## Notes

- `safe_lookahead_distance` is the distance from robot center to the controlled
  virtual point.
- `safe_obstacle_pose_radii` should match `safe_obstacle_pose_topics` in order.
- `safe_obstacle_safety_margin` is added on top of the pose obstacle radius.
- `shooting_offset_x` and `shooting_offset_y` are relative to the goal frame for
  passer and shooter targets.
- The plotter is for debugging only; it does not change the controller output.
